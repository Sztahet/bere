Aktualny pierwszy cel to **pre-PoC**: przejście bohaterem przez spiralny labirynt pod ostrzałem automatycznych wież, bez drużyny obrońców. Zakres minimum i kolejny etap opisuje sekcja 0.1 w GDD. W menu dostępna jest uproszczona przeglądarkowa próba.
