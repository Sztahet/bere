# Riftoryn

Bieżąca wersja gry i kodeksu znajduje się w [projekcie Unity](riftoryn-unity/).

[Archiwalne PoC w przeglądarce](riftoryn-menu.html) obejmuje kodeks 0.2.2, symulator draftu i uproszczoną próbę. [Historia wydań](CHANGELOG.md).

[Archiwum Riftoryn](archiwum-riftoryn.html) udostępnia opowiadania z [katalogu opowiadań](opowiadania/katalog.json). Aktualne rękopisy znajdują się w katalogu [opowiadania](opowiadania/README.md); status każdej części określa pole `draft` w katalogu.

Projekt gry i mechanik opisuje [RIFTORYN_GDD.md](RIFTORYN_GDD.md). Przy poznawaniu i ocenie bohaterów punktem wyjścia są aktualne opowiadania, w tym sceny z innych perspektyw. [Historia świata](world_history.md) opisuje reguły i chronologię świata. Kodeks gry, starsze biografie i propozycje mogą nie nadążać za opowiadaniami; nie zastępują lektury historii.

[Przewodnik po dokumentacji](dokumentacja/README.md) wskazuje materiały projektowe, prompty graficzne oraz archiwalne audyty i szkice.

[Biblioteka grafik](assets/README.md) zawiera portrety, plansze koncepcyjne, ilustracje, bestiariusz i ikony.

Propozycje przyszłego modelowania postaci: [Ana i Bob oraz Koneva i Pati](RIFTORYN_PROPOZYCJE_MODELOWANIA_POSTACI.md).

Strona jest statyczna i może być publikowana przez GitHub Pages z katalogu głównego gałęzi `main`. Plik `index.html` kieruje do kodeksu. Po opublikowaniu pod repozytorium `Sztahet/bere` będzie dostępna pod adresem `https://sztahet.github.io/bere/`.

Zakres pierwszej grywalnej próby i kolejnego etapu opisuje sekcja 0.1 w GDD.
