# Koneva — model PoC

Stylizowany model Konevy odwołuje się do arkusza `assets/heroes/modeling-concepts/koneva-pati.png`. Plik `Koneva_PoC.blend` i eksport `Koneva_PoC.fbx` zawierają siatkę oraz szkielet. Skrypt `build_koneva.py` uruchamia się w Blenderze po wczytaniu `assets/characters/saila/Riftoryn_Female_Base.blend`; po eksporcie skopiuj FBX do `riftoryn-unity/Assets/Resources/Characters/koneva-poc.fbx`.

W Unity Koneva używa tymczasowej proceduralnej animacji, a istniejąca Patka (Pati) zachowuje animacje i testową zdolność Q. Model postaci pozostaje prototypem; geometria, deformacje i materiały wymagają dalszego dopracowania.

Baza powstała na podstawie [BodyChan - BodyKun | Posable Drawing Figures](https://blendswap.com/blend/23521), autor: vinchau, licencja CC0 według strony BlendSwap.
