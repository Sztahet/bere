# Sarna — model PoC

Uproszczony model na podstawie [arkusza Sarny](../../heroes/modeling-concepts/sarna.png), zbudowany na wspólnym szkielecie pozostałych bohaterek. W grze używa tymczasowego proceduralnego ruchu; deformacje, strój, laska, twarz i materiały wymagają dalszej pracy.

Model tworzy `assets/characters/build_sarna_lumen.py` po otwarciu `assets/characters/saila/Riftoryn_Female_Base.blend` i podaniu `-- Sarna`. Eksport w Unity znajduje się w `Assets/Resources/Characters/sarna-poc.fbx`.
